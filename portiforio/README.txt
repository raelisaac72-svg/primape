PORTFÓLIO PROFISSIONAL COM BOOTSTRAP

COMO ABRIR
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador (ou use a extensão Live Server).

PERSONALIZAÇÃO OBRIGATÓRIA ANTES DE ENTREGAR
- Procure por "SEU NOME", "SEU-USUARIO", "SEU-PERFIL" e "seuemail@email.com" no index.html.
- Substitua esses textos pelos seus dados verdadeiros.
- Troque assets/img/avatar.svg por uma foto sua ou avatar próprio (mantenha o nome avatar.svg ou atualize o caminho no HTML).
- Confira os três projetos de exemplo: substitua pelos seus trabalhos reais e coloque os links corretos do GitHub.
- Ajuste a biografia e as habilidades para refletir o que você realmente sabe.
- O template usa Bootstrap 5.3.3 por CDN; é necessária conexão com a internet para carregar o Bootstrap e as fontes.

PUBLICAR NO GITHUB
No terminal, dentro da pasta do projeto:
git init
git add .
git commit -m "feat: personaliza portfolio bootstrap"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/meu-portfolio-bootstrap.git
git push -u origin main

PUBLICAR NA VERCEL
1. Entre em vercel.com usando sua conta GitHub.
2. Escolha Add New > Project.
3. Importe o repositório do portfólio.
4. Para este site estático, mantenha as configurações padrão e clique em Deploy.

OBSERVAÇÃO
O conteúdo pessoal e os links estão como exemplos/ marcadores. Não entregue sem substituir e testar os dados, os projetos e os links.
